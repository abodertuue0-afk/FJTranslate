# FJ Translate

> 📱 **نسخة الويب «مترجم نوسة» (تعمل على الآيفون مجاناً من Safari):** راجعي ملف [NOUSA_GUIDE.md](NOUSA_GUIDE.md) ومجلد `docs`.

تطبيق iPhone أصلي (Swift + SwiftUI) للترجمة بين الإنجليزية والعربية، مع نطق صوتي، ويعمل دون إنترنت بعد الإعداد الأولي.

---

## كيف يعمل دون إنترنت؟

**الترجمة:**
- يستخدم إطار Translation من Apple، وهو نموذج ترجمة عصبي حقيقي يعمل على الجهاز.
- تُنزَّل حزمتا العربية والإنجليزية مرة واحدة (من داخل التطبيق).
- بعدها تتم الترجمة كاملة على الآيفون، ولا يُرسل أي نص إلى خادم.
- النموذج غير مدمج داخل التطبيق، لذلك حجم التطبيق صغير، والنظام يدير الذاكرة والبطارية.

**النطق:**
- يستخدم AVSpeechSynthesizer مع الأصوات المثبتة على الآيفون فقط.
- التطبيق يفحص وجود صوت عربي وصوت إنجليزي، ويخبرك إذا كان أحدهما ناقصاً.
- فيه سرعة نطق، إيقاف مؤقت، وإعادة تشغيل.

---

## المتطلبات

- iPhone بنظام iOS 18 أو أحدث.
- اتصال إنترنت مرة واحدة فقط لتنزيل حزم اللغة والأصوات.
- الترجمة لا تعمل على المحاكي (Simulator)، يجب الاختبار على آيفون حقيقي.

## بناء التطبيق دون Mac (عن طريق GitHub)

1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع كل محتوى هذا المجلد كما هو (مع مجلد `.github`).
3. افتح تبويب **Actions** في المستودع.
4. سيبدأ البناء تلقائياً على جهاز Mac سحابي.
5. عند النجاح ستجد ملف **FJTranslate-unsigned-ipa** في أسفل صفحة التشغيل.
6. إذا فشل البناء، انسخ سجل الخطأ وأرسله لإصلاحه.

> ملف IPA غير موقّع لا يُثبَّت مباشرة على الآيفون. يجب توقيعه بإحدى الطرق التالية.

## تثبيت التطبيق على الآيفون

### الطريقة 1: TestFlight (لا تحتاج Mac) — الموصى بها
تحتاج حساب Apple Developer مدفوع (99 دولاراً سنوياً).

1. سجّل في Apple Developer Program.
2. في App Store Connect أنشئ تطبيقاً جديداً بمعرّف: `com.fjtranslate.app`
3. من App Store Connect ← Users and Access ← Integrations ← أنشئ مفتاح API بصلاحية **Admin**.
4. نزّل ملف المفتاح `.p8` واحفظ Key ID و Issuer ID.
5. في GitHub افتح: Settings ← Secrets and variables ← Actions.
6. أضف هذه الأسرار (Secrets):
   - `ASC_KEY_ID` = رقم المفتاح
   - `ASC_ISSUER_ID` = Issuer ID
   - `ASC_KEY_P8` = محتوى ملف .p8 كاملاً
   - `APPLE_TEAM_ID` = رقم الفريق (Team ID)
7. أضف متغيراً (Variable): `ENABLE_TESTFLIGHT` = `true`
8. شغّل البناء من جديد من تبويب Actions.
9. بعد دقائق يظهر التطبيق في TestFlight.
10. ثبّت تطبيق TestFlight على الآيفون، ومنه ثبّت FJ Translate.

### الطريقة 2: Mac مع Xcode (مجاني لمدة 7 أيام)
1. ثبّت Xcode وXcodeGen على جهاز Mac.
2. في مجلد المشروع نفّذ: `xcodegen generate`
3. افتح `FJTranslate.xcodeproj`.
4. من Signing & Capabilities اختر حساب Apple ID الخاص بك.
5. صِل الآيفون واضغط Run.
6. التوقيع المجاني ينتهي بعد 7 أيام ويحتاج إعادة.

### الطريقة 3: أدوات التوقيع من Windows (Sideloadly / AltStore)
- تحتاج Windows بنظام 64-bit، ولا تعمل على Windows 32-bit.
- توقّع ملف IPA غير الموقّع بحساب Apple ID (صلاحية 7 أيام).

## الإعداد الأول على الآيفون

1. افتح التطبيق وأنت متصل بالإنترنت.
2. ستظهر شاشة **الإعداد**.
3. اضغط **تنزيل الحزم الآن** ووافق على نافذة iOS.
4. إذا ظهر أن صوتاً ناقصاً، اتبع **طريقة تنزيل أصوات أوضح**.
5. فعّل وضع الطيران.
6. اضغط **ابدأ الاختبار**.
7. يجب أن تظهر الترجمتان مع علامة «دون إنترنت ✓».
8. اضغط السماعة بجانب كل نتيجة للتأكد من النطق.

## تنزيل الأصوات يدوياً

1. الإعدادات
2. تسهيلات الاستخدام
3. المحتوى المنطوق
4. الأصوات
5. العربية ← نزّل صوتاً (الأفضل: محسّن أو ممتاز)
6. ارجع ← الإنجليزية ← نزّل صوتاً

## الميزات

- ترجمة إنجليزي ⇄ عربي أثناء الكتابة، مع الحفاظ على الأسطر.
- كشف تلقائي للغة النص.
- زر تبديل الاتجاه.
- استماع للنص الأصلي والترجمة، سرعة، إيقاف مؤقت، إعادة.
- نسخ، لصق، مسح، مشاركة.
- السجل والمفضلة مع البحث (محفوظة على الجهاز فقط).
- وضع داكن وفاتح.
- واجهة عربية RTL، والنص الإنجليزي LTR تلقائياً.
- رسائل واضحة عند: عدم تنزيل الحزم، انقطاع الاتصال، نقص المساحة، غياب الأصوات.

## هيكل المشروع

```
project.yml                  ← تعريف مشروع Xcode (XcodeGen)
.github/workflows/build.yml  ← البناء السحابي و TestFlight
FJTranslate/
  App/FJTranslateApp.swift
  Models/        اللغات، سجل الترجمة (SwiftData)
  Services/      النطق، حزم اللغة، الشبكة، التخزين، كشف اللغة
  ViewModels/    منطق الترجمة
  Views/         الشاشات
  Resources/     الأيقونة والألوان
```

## حدود يجب معرفتها

- جودة الترجمة هي جودة نموذج Apple المحلي.
- جودة الصوت العربي تعتمد على الصوت الذي تنزّله (الأصوات «المحسّنة» أوضح بكثير).
- في بعض إصدارات iOS قد يظهر خطأ «النموذج غير جاهز» رغم التنزيل؛ الحل: حذف اللغة وإعادة تنزيلها من الإعدادات ← التطبيقات ← ترجمة.
